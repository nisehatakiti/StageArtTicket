# StageArtTicket

StageArtCoreの拡張プラグインとして、舞台公演のチケット予約・受付管理を提供します。

## 依存関係

- StageArtCore
- AuthCore

## 対象機能

- 公演回ごとの総席数管理
- オンライン予約（決済なし）
- 予約番号による予約管理
- 予約名・メールアドレス管理
- 公演回ごとの受付一覧・チェックイン
- 当日券の登録・即時受付
- AuthCoreユーザーに紐づく「誰扱い」
- 通常予約ページと「誰扱い」固定予約ページ
- 「誰扱い」別の予約・受付集計

チケット種別・料金・金銭売上管理はStageArtTicketの責務ではありません。公演の「チケット料金」はStageArtCoreの公演情報として管理されます。
